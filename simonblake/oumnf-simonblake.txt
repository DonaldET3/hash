OUmanifest extensions for SimonBLAKE hash functions
version 1

function name for SimonBLAKE: simonblake

specification fields
The "size" field specifies the number of bits in the hash output. (default: 512)
The "rounds" field specifies the number of rounds used to process the data.
The "endian" field specifies whether the bytes are loaded into words in "big" order (most significant byte first), or "little" order (least significant byte first). (default: little)
