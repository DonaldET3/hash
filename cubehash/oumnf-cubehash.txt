OUmanifest extensions for CubeHash hash functions
version 1

function name for CubeHash: cubehash

specification fields
The "init" field specifies the number of rounds used to initialize the function.
The "rounds" field specifies the number of rounds used to process the data.
The "block" field specifies the number of bytes per data block.
The "final" field specifies the number of rounds used to finish the hash.
The "size" field specifies the number of bits in the hash output. (a multiple of 8)
The "wordsize" field specifies the number of bits in the integers used in the hash computation. (default: 64)
The "endian" field specifies whether the bytes are loaded into words in "big" order (most significant byte first), or "little" order (least significant byte first). (default: little)
